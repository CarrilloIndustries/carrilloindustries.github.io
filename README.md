# carrilloindustries.com

The source of [carrilloindustries.com](https://carrilloindustries.com), the Carrillo Industries portfolio
page, served by GitHub Pages from this repository's `main` branch.

- `index.html`: the whole page, laid out like a component datasheet. Plain HTML and CSS, with no
  build step; edit it and push.
- `assets/`: favicon, share image (shown in link previews) and the WPF template screenshot.
- `CNAME`: tells GitHub Pages to serve the site at carrilloindustries.com.

When the page changes, bump its revision letter and add a line to its revision history table.
